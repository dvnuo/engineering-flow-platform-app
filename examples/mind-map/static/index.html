Mind maps

 

Think in branches,
tidy by itself.

A map is yours alone until you share it. Type an idea, press Tab for a child and Enter for a sibling: the map makes room and every branch finds its place.

You are not signed in: you can open the maps others share, not draw your own.

Keys of the editor

They work while the map has the focus: click it, or reach it with Tab.

Tab
add a child
Enter
add a sibling
F2
rename (or double click)
Del
delete the branch
Space
fold or unfold
← ↑ ↓ →
walk through the map
Alt + ↑ ↓
change the order
M
move to another parent (or drag it)
Ctrl + Z / Y
undo, redo
Ctrl + S
save
+ - 0
zoom in, zoom out, the whole map
Esc
let go of the map, so that Tab moves on
