Dev toolbox

Ten small tools that run in this tab

    No tool is called that. Esc shows them all.

    Nothing leaves this tab. This app has no backend. Every tool runs in your browser; what you paste is not sent, stored or logged anywhere.

    Ctrl K
    find a tool
    Alt 1-0
    open tool 1 to 10
    Alt ↑ ↓
    previous, next tool
    /
    filter the list
